# Service Twin AI v0.7

v0.7 的核心升级：**交互逻辑与易用性重构**。

这一版不继续堆模型能力，而是把工具从“功能模块集合”重构为“服务体验仿真工作台”。

## v0.7 核心变化

### 1. 五步向导式流程

原来的多 Tab 功能被重构为：

1. 服务场景
2. 服务流程
3. 参数设置
4. 体验仿真
5. 蓝图与建议

### 2. Step 3 从“参数缺口问答”改为“直接参数设置”

不是连续提问，而是直接显示关键参数：

- 每小时到店组数
- 检测台数量
- 检测平均时长
- 报价沟通时长
- 数据清除时长
- 设计干预开关

每个参数附带来源标记：

- AI 假设
- 人工输入
- 现场观察
- 系统数据
- 待验证

### 3. 关键参数减少

保留对服务体验仿真影响最大的参数，高级参数暂时隐藏。

### 4. 结果摘要优先

运行后优先显示：

- 整体流失率
- 整体成交率
- 平均清晰度
- 平均信任感
- 主要流失节点

再展开用户类型、节点风险和路径样本。

### 5. 蓝图与建议作为最终交付页

最终页整合：

- 体验仿真蓝图
- 关键发现
- 优先优化建议
- 下一步验证计划
- 客户汇报摘要

## 快速开始

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

没有 API Key 时，会使用 mock 输出。
